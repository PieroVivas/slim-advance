## 🌐 Cómo Desplegar en GitHub Pages Gratis ($0 Costo)

1. En GitHub, crea un repositorio llamado `slim-advance` (Público).
2. Sube los archivos con los comandos:
   ```bash
   git remote add origin https://github.com/TU-USUARIO/slim-advance.git
   git push -u origin main
   ```
3. En GitHub, ve a **Settings** > **Pages**:
   * En **Source**: `Deploy from a branch`
   * En **Branch**: `main` y `/ (root)`
   * Guarda los cambios.
4. Tu sitio web se verá en vivo en: `https://TU-USUARIO.github.io/slim-advance/`
